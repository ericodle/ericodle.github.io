# ericodle.github.io

Web development work. Served by GitHub Pages at https://ericodle.github.io/.

Plain HTML and CSS, no build step: `index.html` and `style.css` are the site.
Open `index.html` in a browser to preview. Push to `main` to publish.

To add a project, copy one `<li>` in the right group and change the link,
name, address, description and stack. The groups:

- **Personal Projects**: my own sites.
- **Full Creative Control**: client work where I had full design and
  development control.
- **Commissioned Work**: a major share of the web work, done as a temporary
  employee or contractor on someone else's team.

`logo.svg` is the brand logo and favicon: 歐艾瑞 (Noto Serif CJK TC Black)
cut north to south down a green map of Taiwan, with the coast and county
lines in orange (g0v/twgeojson, public domain). `favicon.ico` and
`apple-touch-icon.png` are PNG copies of it for browsers that skip SVG icons.

Photography lives at https://ouairei.com/.
